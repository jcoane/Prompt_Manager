1. Install and Start

Run PromptManagerSetup.exe. Windows may request administrator permission. The default destination is C:\Program Files (x86)\Prompt Manager; use Browse or edit the location to choose another folder. An existing registered installation location is used when detected.

  1. Save your edits and close Prompt Manager before upgrading. Setup refuses to force-close a running application.
  2. Choose the installation destination and optional Desktop and Start menu shortcuts.
  3. Select Install. The package contains the application, .NET desktop runtime, SQLite components, logo, and this manual. No separate runtime download is required.
  4. Start with the Prompt Manager shortcut, Start menu entry, or PromptManager.exe in the installation directory.

Installation and uninstallation do not intentionally delete the library stored in your local application data. Make a separate backup before an upgrade. The first opening of an older library makes a pre-upgrade backup before its database schema is migrated. A new library starts empty.

This is a standalone local tool. It provides no login, cloud synchronization, AI execution, analytics, encryption, electronic signatures, or formal approval workflow. The Approved status is a user-selected label, not a quality approval or validated state. Apply your organization's procedures where required.

2. Workspace

The single-window workspace has navigation on the left, a spreadsheet-style register in the center, and the properties/editor panel on the right. The top level uses darker pastel colors; working surfaces below use lighter shades.

Drag the pane dividers to resize. Columns, widths, order, sorting, pane widths, and reading size are stored locally when the window closes normally. Ctrl+F focuses Search, Ctrl+N creates a prompt, and Ctrl+S saves.

3. Create and Edit Records

  1. Select a directory, then select New Prompt. A Draft record is created and selected. An active search is cleared so the new record remains visible.
  2. Enter a specific title. Type is an editable list: the default is Prompt; a custom value becomes available after it is saved.
  3. Select Mode, Path, and Status. Enter searchable tags and optional labels. Labels accept semicolons or commas.
  4. Edit the Prompt text and Notes. The Unsaved indicator identifies edits not yet stored.
  5. Select the save icon or Ctrl+S. If controlled fields changed, supply a meaningful change note in the Save Revision dialog. A new snapshot is recorded.

Changing selection, search, directory, or closing the main window prompts you to Save, Discard, or Cancel when edits are pending. Cancel keeps your current work. If a record changed since it was opened, the save is rejected and edits remain in the editor: copy them out before refreshing, then reconcile against the latest record.

4. Directories and Moving

Select a folder before using New Folder to create a child; select All Folders to create a top-level folder. Empty names and duplicate sibling names are rejected. Rename updates displayed paths. Move chooses a new parent; moving into itself or a descendant is rejected.

Move a single prompt by selecting its Details > Path and saving. For several prompts, use Ctrl-click or Shift-click in the register, then select its move icon. Choose the destination. The moves are committed together and each changed prompt receives a history entry. The register and folder tree refresh to the destination.

Deleting a directory deletes its descendants but moves contained prompts to Unfiled instead of deleting them. That relocation is recorded in each affected prompt's history. Confirm the warning carefully. Permanent prompt deletion is separate and also removes its version history; use Archive for recoverable retirement.

5. Notes and Reading

Notes has a full-height editor. Select text, then B for bold, I for italics, or a font color. Formatting is stored as RTF alongside searchable plain text. The reading-size list changes display size; it is not a new prompt revision.

The expand icon on Notes or Prompt opens that editor in a larger window. Done returns to the main window with edits retained, but does not save a revision. Use Save in the main window. Notes scroll independently; the Prompt tab supports multiline plain text.

6. Review and History

Review lists advisory checks for missing context, tags, labels, template sections, placeholders, and possible duplicate text or titles. These checks are heuristics. They do not assess scientific correctness or establish regulatory compliance.

Versions lists saved revisions with time and change note. Select a revision to inspect Saved Text and Differences against the current editor. Differences include available metadata and an ordered line comparison, including repeated and blank lines. Very large comparisons show a bounded-diff notice; complete saved and current text remain accessible.

Restore Revision as Draft asks for a reason and creates a new Draft revision. Newer history is retained, and prior Approved status is not automatically reinstated. A historical directory that no longer exists becomes Unfiled. Older libraries may lack historical metadata; missing information must not be inferred as a factual historic value.

Archive and restore from archive also create history entries. Favorite flags and copying/usage dates do not create controlled revisions. Folder name/parent changes update current paths; they do not create a separate folder audit log.

7. Variables and Copying

Variables use {{Name}}. A name starts with a letter or underscore and may then include letters, numbers, underscores, dots, and hyphens. Insert Variable adds one at the cursor.

Select Fill Variables and Copy to enter local values and inspect the generated preview. All detected variables require a nonblank value before copying. Repeated names are filled consistently, without changing the stored template. No model is contacted. The normal copy icon copies the current editor text, including unsaved text; it does not save those edits. Clipboard contents are accessible to other applications and may be retained by Windows Clipboard History.

8. Search and Views

Search covers Type, Mode, Labels, Title, Body, Tags, and plain Notes. It is combined with the selected view and selected folder, including descendants. Clear search and select All Folders / All Prompts to broaden results. Retired contains archived records and records marked Retired. All Prompts excludes archived records.

The register initially shows Name, Status, Type, Tags, Version, and Modified. Mode, Labels, Path, and Favorite are optional in Columns. Name always remains visible. Search uses SQLite FTS5 prefix terms where available, with a text-search fallback when FTS is unavailable.

9. Import and Export

Choose File > Export > Selected Prompts, Current View, or Entire Library. Current View exports the displayed result set. Entire Library includes archived records and all directories. Selected/current-view exports include their required directory ancestors and historical references. Exports contain saved data; pending edits must first be saved or discarded.

JSON export format is PromptManager.Export, version 1.4. It includes records, directories, and version snapshots. Import accepts supported 1.x formats through 1.4, rejects invalid/circular structures, remaps directory identifiers, and commits all records together. Imports add new prompt records; repeating an import can create duplicates. There is no automatic merge. Historical empty fields remain empty rather than being replaced by today's values.

Exports, backups, and the library are not encrypted. Protect them using appropriate Windows access controls. Do not place confidential files in a synchronized folder unless that transfer is authorized.

10. Backup and Restore

  1. Choose File > Backup Library, then a local destination. Backup uses SQLite's snapshot mechanism so committed write-ahead-log data is included.
  2. For a restore, first save your current work and close any other tool using the database.
  3. Choose File > Restore Library and the backup file. Check the confirmation: restore replaces the entire library, not just the current view.
  4. The candidate is checked for database integrity, schema compatibility, relationships, and loadability. Migration occurs on a temporary copy.
  5. A unique pre-restore backup of the current library is created, then the staged database replaces it. The application displays the safety backup path.

A failed candidate validation does not replace the active library. Keep backups on a separate approved drive as needed, and periodically verify a restore against a non-production copy. Backups are technical recovery records, not formal validation evidence.

13. Legacy History Recovery

When older history has no matching prompt, startup offers to preserve these detached entries. Recovery creates a pre-recovery-*.db safety backup, then transfers the original version fields into RecoveryHistory. Current prompts and folders are not changed. Help > Recovery Records displays this evidence read-only.

Recovery fieldType and meaning
IdINTEGER recovery key
OriginalVersionId / OriginalPromptId / VersionNumberINTEGER original references
SnapshotJsonTEXT; JSON object containing every original SQLite field
RecoveredAt / ReasonTEXT; actual recovery time and explanation

Normal backups and Entire Library JSON exports include recovery entries. Scoped prompt exports do not. Pre-recovery backups retain their original broken relationships and need relationship repair before a normal restore will be accepted. Recovery entries are historical evidence, not new approved prompts. Folder structures are limited to 256 levels.
